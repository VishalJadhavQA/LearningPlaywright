# Learning Playwright with AI

This repository is dedicated to learning Playwright automation through structured chapters. It covers everything from basic setup to advanced JavaScript concepts used in automation.

## Project Structure

### 📂 Chapter 01: Basics
Basic introduction and environment verification.
- `01_Verify_Setup.js`: Initial script to verify the Playwright environment.
- `02_Comments.js`: Examples of single-line and multi-line comments in JavaScript.

### 📂 Chapter 02: JS Concepts
Deep dive into JavaScript fundamentals essential for automation.
- `03_Literals.js`: Understanding Identifiers, Literals, and Operators.

## How to Run
Ensure you have Playwright installed:
```bash
npm install @playwright/test
```

To run a specific script:
```bash
node Chapter_01_Basics/01_Verify_Setup.js
```
